# Limpeza-de-Dados-Power-Query
Limpeza e padronização de 10 mil registros de vendas com dados sujos, usando Power Query no Excel.

Projeto de tratamento de dados feito no Excel com Power Query. A base original tem 10 mil pedidos com problemas típicos de dados reais: datas em vários formatos, valores monetários escritos de formas diferentes (R$, parênteses, vírgula e ponto), textos com maiúsculas e espaços inconsistentes, valores ausentes (N/A, nd, vazio) e quantidades inválidas (negativas e outliers como 999999).

O que foi feito: padronização de datas, conversão de tipos, tratamento de moeda e percentuais, limpeza de texto (produto, região, vendedor, canal e status) e criação das colunas de valor total bruto e valor total líquido.

Ferramentas: Excel, Power Query.

Arquivos: aba DADOS ORIGINAIS (base crua) e DADOS LIMPOS (resultado final).
